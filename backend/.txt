200 → Request succeeded
201 → Resource created
204 → Request succeeded, nothing to return

400 → Client sent invalid data
401 → User is not logged in / token invalid
403 → User is logged in but doesn't have permission
404 → Resource doesn't exist
409 → Resource/state conflict
422 → Validation failed
429 → Too many requests

500 → Something unexpectedly broke on the server
502 → Upstream service failed
503 → Server/service unavailable
504 → Upstream service timed out
